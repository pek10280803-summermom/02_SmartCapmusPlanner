# 📅 Smart Campus Planner

대학생을 위한 아주 간단한 **할 일(To-Do) 관리 웹앱**입니다.
학과 과제, 동아리 활동, 개인 할 일을 한 화면에서 함께 관리할 수 있습니다.

---

## 🎯 만든 목적

대학생은 학과 과제, 동아리 활동, 개인적인 약속 등 여러 종류의 일정을 동시에 챙겨야 합니다.
하지만 이런 일정들이 서로 다른 메모장, 앱, 캘린더에 흩어져 있으면 마감일을 놓치거나 무엇이 더 급한 일인지 헷갈리기 쉽습니다.

**Smart Campus Planner**는 이런 문제를 해결하기 위해 만들어졌습니다.
학과 / 동아리 / 개인 할 일을 **하나의 목록**에서 관리하고, 각 할 일의 **중요도**와 **마감일**을 함께 표시해주어서, 한눈에 무엇을 먼저 해야 하는지 파악할 수 있도록 도와줍니다.

---

## ✨ 주요 기능

| 기능 | 설명 |
|------|------|
| ✅ 할 일 추가 | 제목을 입력하고 목록에 새로운 할 일을 추가할 수 있어요. |
| 🏷️ 카테고리 설정 | 할 일을 **학과 / 동아리 / 개인** 중 하나로 분류할 수 있어요. |
| ⭐ 중요도 설정 | 할 일의 중요도를 **상 / 중 / 하**로 지정할 수 있어요. |
| 📆 마감일 지정 | 할 일마다 마감 날짜를 지정하고 확인할 수 있어요. |
| ☑️ 완료 체크 | 체크박스를 눌러 완료 여부를 표시할 수 있어요. 완료된 할 일은 취소선으로 구분돼요. |
| 🗑️ 삭제 | 더 이상 필요 없는 할 일은 삭제 버튼으로 목록에서 지울 수 있어요. |
| 📊 완료율 표시 | 전체 할 일 중 몇 %를 완료했는지 화면 상단에서 바로 확인할 수 있어요. |
| 💾 새로고침해도 유지 | 브라우저를 새로고침하거나 다시 열어도 입력했던 할 일이 그대로 남아있어요. |

---

## 🖥️ 사용 방법

1. 이 프로젝트 폴더에 있는 `index.html` 파일을 더블클릭해서 웹 브라우저로 엽니다.
   (또는 아래 GitHub Pages 링크로 바로 접속할 수도 있습니다.)
2. 화면 위쪽 입력창에 할 일 제목을 입력합니다.
3. 카테고리(학과 / 동아리 / 개인), 중요도(상 / 중 / 하), 마감일을 선택합니다.
4. **추가** 버튼을 누르면 목록에 할 일이 추가됩니다.
5. 완료한 할 일은 체크박스를 눌러 완료 표시를 하고, 필요 없는 할 일은 **삭제** 버튼으로 지울 수 있습니다.
6. 화면 위쪽에서 전체 할 일 대비 완료율(%)을 확인할 수 있습니다.
7. 브라우저를 새로고침하거나 나중에 다시 접속해도 입력한 내용은 그대로 남아있습니다.

> 별도의 회원가입이나 설치 과정 없이, 파일을 열기만 하면 바로 사용할 수 있습니다.

---

## 🛠️ 사용한 기술

- **HTML** : 화면의 구조(입력창, 버튼, 목록 등)를 구성
- **CSS** : 화면의 디자인(색상, 레이아웃, 태그 스타일 등)을 꾸밈
- **JavaScript** : 할 일 추가·완료·삭제·완료율 계산 등 실제 동작을 처리
- **localStorage (브라우저 저장소)** : 별도의 서버나 데이터베이스 없이, 브라우저 안에 할 일 데이터를 저장하여 새로고침 후에도 유지되도록 함

이 프로젝트는 별도의 서버 없이 브라우저에서만 동작하는 **정적 웹페이지**로 만들어졌습니다.
